# EGH490_William_Computer_vision_for_safer_cities
Code repository for William Smith's EGH490 project. Includes code for developed data cleaning editor and model training and evaluation.
Programming languages used: Python.

Instructions for using the data cleaning UI:

Create a file structure within a virtual environment where:
data_cleaning_ui.py is within the lowest level of the directory where the venv is stored
NHRA_dataset folder is within another folder called data
annotations are within the NHRA folder
images are stored within a val folder within the NHRA dataset folder

Chnage the variable image_index to n-1 the image you wish to start from (if cleaning done over multiple sessions)

Run the file using the commands supplied within the code file.

Please refer to instructions at the top of coco_annotation_editor.py for further details on UI functionality

Additional information regarding evaluation metrics included within information folder (To be added).
Please note commands for running scripts are currently configured for Linux environments.
